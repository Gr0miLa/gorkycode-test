# Голосовой ассистент для задач и встреч

Прототип принимает свободные текстовые и голосовые команды, создает задачи и
встречи, показывает планы за период и ищет старые события.

## Локальный запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
alembic upgrade head
uvicorn app.main:app --reload
```

Откройте `http://127.0.0.1:8000`. Для обработки команд заполните
`GIGACHAT_AUTH_KEY` в `.env`.

## Docker

```bash
cp .env.example .env
docker compose up -d --build
```

SQLite хранится в persistent Docker volume и не пропадает при перезапуске
контейнера. При старте контейнер автоматически применяет миграции. Seed-данные
не импортируются по умолчанию и не отображаются пользователям. `IMPORT_SEED`
оставлен только для тестовых/демонстрационных баз; в production его включать не
нужно. Перед приложением следует настроить
Caddy или Nginx с HTTPS: браузер предоставляет микрофон только в безопасном
контексте.

Если seed-данные уже были импортированы в существующую базу, удалите их один раз:

```bash
python -m scripts.clear_seed
```

## Проверка

```bash
pytest -q
```

Примеры запросов:

- `Напомни завтра в 10 позвонить Ивану`;
- `Добавь встречу с командой завтра в 15:00`;
- `Что у меня на этой неделе?`;
- `Найди задачу про договор`.

Подробные решения и порядок разработки описаны в `IMPLEMENTATION_PLAN.md`.
